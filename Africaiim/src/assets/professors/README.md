# Professor Images

## Image Requirements

Place professional headshot photos of the professors in this folder with the following specifications:

### Required Files:
- `hubert-silly.jpg` - Dr. Hubert Silly (Rector)
- `karim-dehimi.jpg` - Karim Dehimi (Director)
- `radjkoumar-damien.jpg` - Radjkoumar Damien (Head of Banking)

### Image Specifications:
- **Format**: JPG or PNG
- **Dimensions**: 800x800 pixels (square format)
- **File size**: Under 500KB (optimized)
- **Quality**: High resolution, professional headshots
- **Background**: Preferably solid or blurred professional background
- **Composition**: Head and shoulders, professional attire

### Naming Convention:
Use lowercase with hyphens for file names matching the pattern above.

### Temporary Placeholders:
Until actual photos are provided, the system uses placeholder images from Unsplash.
